# Interface assets — Member C

`imagery/` contains four generated, optimized photographic assets and their exact prompts. `fonts/` contains local Inter and Outfit Latin variable-font files with their licenses. These are interface assets, separate from customer evidence.

`brand/` contains the user's supplied light/dark logo PNGs. The shared brand component and browser icon select the matching theme variant.

The current UI prototype saves customer image previews in browser IndexedDB. MongoDB GridFS remains the production integration target. Synthetic UI evidence is generated by `ui/gateway.jac`; the small PNG under `tests/fixtures/` is a synthetic upload fixture. Keep live customer uploads, local dependency directories, and generated build output out of the source bundle.
